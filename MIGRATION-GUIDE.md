# Руководство по миграции: Claude Code → Qwen Code

Это руководство описывает процесс перехода с Claude Code на Qwen Code в проекте Infinite Brain OS.

## Что изменилось

### Новая структура адаптеров

- **Основной адаптер**: `.qwen/` - теперь основная директория адаптера для Qwen Code
- **Обратная совместимость**: `.claude/` и `.codex/` по-прежнему поддерживаются
- **Ориентационные файлы**: 
  - `QWEN.md` - основной файл ориентации для Qwen Code
  - `AGENTS.md` - основной файл ориентации для Codex и других агентов
  - `CLAUDE.md` - сохранен для обратной совместимости

### Обновленные файлы

1. **README.md** - обновлены упоминания сред исполнения, добавлены ссылки на Qwen Code
2. **START-HERE.md** - добавлена информация о новой структуре адаптеров
3. **sync-adapters.sh** - обновлен для поддержки `.qwen/` директории
4. **Рабочие процессы и инструменты** - обновлены упоминания Claude Code на Qwen Code

## Для новых пользователей

Если вы начинаете работу с Infinite Brain OS впервые:

1. Установите [Qwen Code](https://github.com/QwenLM/qwen-code.git)
2. Клонируйте репозиторий
3. Запустите `bash _system/validate.sh` для проверки целостности
4. Запустите Qwen Code с командой `qwen-code`
5. При первом запуске Qwen Code прочитает `QWEN.md` для ориентации

## Для существующих пользователей

Если вы уже использовали Claude Code:

### Вариант 1: Полная миграция (рекомендуется)

1. Обновите свой локальный репозиторий до последней версии
2. Установите Qwen Code
3. Удалите директорию `.claude/` (если она существует):
   ```bash
   rm -rf .claude/
   ```
4. Запустите синхронизацию адаптеров:
   ```bash
   bash sync-adapters.sh
   ```
5. Проверьте валидацию:
   ```bash
   bash _system/validate.sh
   ```
6. Начните использовать Qwen Code вместо Claude Code

### Вариант 2: Поддержка обоих адаптеров

Проект поддерживает одновременное существование `.claude/`, `.codex/` и `.qwen/`. 
Вы можете продолжать использовать Claude Code, пока переходите на Qwen Code.

## Изменения в скрипте sync-adapters.sh

Скрипт `sync-adapters.sh` теперь поддерживает три адаптера:

```bash
# Основной адаптер для Qwen Code
Qwen_Map="
agents
commands
skills
rules
"

# Адаптеры для обратной совместимости
Claude_Map="..."
Codex_Map="..."
```

## Проверка миграции

После миграции выполните следующие проверки:

1. **Валидация**: `bash _system/validate.sh` должен завершаться с exit code 0
2. **Структура директорий**: Убедитесь, что `.qwen/` содержит все необходимые поддиректории
3. **Файлы ориентации**: `QWEN.md` и `AGENTS.md` должны быть актуальными
4. **Рабочие процессы**: Все рабочие процессы должны корректно ссылаться на Qwen Code

## Решение проблем

### Проблема: Валидатор показывает ошибки после миграции

**Решение**: Проверьте, что все файлы корректно обновлены. Запустите скрипт синхронизации адаптеров повторно:
```bash
bash sync-adapters.sh
bash _system/validate.sh
```

### Проблема: Qwen Code не читает QWEN.md

**Решение**: Убедитесь, что Qwen Code запущен из корневой директории проекта и имеет доступ к файлам.

### Проблема: Отсутствуют файлы в `.qwen/` директории

**Решение**: Выполните полную синхронизацию:
```bash
rm -rf .qwen/
bash sync-adapters.sh
```

## Обратная совместимость

Проект сохраняет обратную совместимость:

- **Codex**: Продолжает использовать `.codex/` адаптер и `AGENTS.md`
- **Claude Code**: Может продолжать использовать `.claude/` адаптер и `CLAUDE.md`
- **Существующие рабочие процессы**: Будут корректно работать с обновленными файлами

## Преимущества перехода на Qwen Code

1. **Активная разработка**: Qwen Code активно развивается
2. **Улучшенная интеграция**: Лучшая интеграция с Infinite Brain OS
3. **Расширенные возможности**: Больше инструментов и функций
4. **Будущая поддержка**: Основной фокус развития проекта
