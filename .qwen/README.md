# .qwen/ , Qwen Code Adapter

This folder is the Qwen Code runtime adapter for the canonical entities in `entities/`.

Files in `.qwen/commands/`, `.qwen/agents/`, `.qwen/skills/`, `.qwen/rules/` are
shims mirroring the canonical entity files in `../entities/`: plain copies regenerated by
`sync-adapters.sh` (the default, and what ships in this repo), or symbolic links where a
platform supports them.

Qwen Code loads these shims through its native loader. The shim is transparent either
way: edit the canonical file in `entities/`, never the shim, and re-run
`bash sync-adapters.sh` after editing when the shims are copies.

`.qwen/hooks/` is different: it contains runtime-specific shell scripts (and the
`README.md` that documents them) that enforce rules during a session. Hooks are not
entities and do not participate in the adapter pattern. They stay in `.qwen/hooks/`
and they have no .codex equivalent.

See `entities/README.md` for the canonical/adapter pattern and `sync-adapters.sh` at
the repo root for the Windows-portable fallback.
